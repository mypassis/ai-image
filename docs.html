Everything you need to integrate AI image generation into your applications

Quick Start Guide

Get started with PixelForge AI in just a few minutes. Our API makes it easy to generate stunning images from text descriptions.

Note: You'll need an API key to access the PixelForge AI service. Sign up at pixelforge.ai to get your free API key.

Installation

No installation required! Simply include our JavaScript SDK in your project:

<script src="https://cdn.pixelforge.ai/sdk/v1/pixelforge.min.js"></script>

Basic Example

Generate your first image with just a few lines of code:

const response = await pixelforge.generate({ prompt: "A beautiful sunset over mountains", style: "photorealistic", size: "1024x1024" }); console.log(response.image_url);

Authentication

All API requests require authentication using your API key. Include it in the Authorization header:

Authorization: Bearer YOUR_API_KEY

Image Generation API

The main endpoint for generating images from text descriptions.

Endpoint

POST /v1/images/generations

Parameters

Parameter Type Required Description
prompt string Yes Description of the image to generate
style string No Art style (photorealistic, artistic, abstract)
size string No Image dimensions (1024x1024, 512x512, etc.)
count integer No Number of images to generate (1-10)

Example Request

fetch('https://api.pixelforge.ai/v1/images/generations', { method: 'POST', headers: { 'Content-Type': 'application/json', 'Authorization': 'Bearer YOUR_API_KEY' }, body: JSON.stringify({ prompt: 'A futuristic city with flying cars', style: 'photorealistic', size: '1024x1024', count: 1 }) })

Response Format

The API returns a JSON response with the generated image URLs:

{ "success": true, "data": { "images": [ { "url": "https://cdn.pixelforge.ai/generated/abc123.png", "width": 1024, "height": 1024, "prompt": "A futuristic city with flying cars" } ], "credits_used": 1, "remaining_credits": 99 } }

Basic Usage Tutorial

Follow these steps to integrate PixelForge AI into your application:

Step 1: Initialize the SDK

const pf = new PixelForge({ apiKey: 'YOUR_API_KEY' });

Step 2: Generate an Image

pf.generateImage({ prompt: 'A serene lake surrounded by mountains', style: 'painting', size: '1024x768' }).then(result => { console.log('Generated:', result.url); });

Step 3: Display the Result

const img = document.createElement('img'); img.src = result.url; document.body.appendChild(img);

Advanced Features

Style Customization

Choose from various art styles to match your vision:

  • 📷 Photorealistic - Realistic photography style
  • 🎨 Oil Painting - Classical painting technique
  • ✏️ Sketch - Hand-drawn pencil sketch
  • 🌈 Abstract - Modern abstract art
  • 🎮 Anime - Japanese animation style

Batch Processing

Generate multiple variations of your prompt:

const results = await pf.batchGenerate({ prompts: [ 'A cat in space', 'A dog on the moon', 'An eagle flying over clouds' ], style: 'photorealistic' });

Frequently Asked Questions

How many images can I generate?

Free accounts get 10 images per day. Pro accounts get 1000 images per day. Enterprise plans offer unlimited generation.

What image formats are supported?

We currently support PNG and JPEG formats. WebP support is coming soon.

Can I use generated images commercially?

Yes! All images generated through PixelForge AI can be used for commercial purposes. You own full rights to your creations.

How long does generation take?

Most images are generated within 5-15 seconds depending on complexity and server load.
